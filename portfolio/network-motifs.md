# 加密资产转账的时序网络Motif研究

- [公开研究代码与图形资产](https://github.com/Dxfory/Understanding-cryptocurrency-transactions-with-network-motifs)

以时序网络motif分析转账结构，结合小时/日尺度图形与随机零模型对照，研究交易活动、地址网络与局部结构。

公开仓库包含notebook、motif分析、随机零模型、中心性/异常分析文件，以及1小时/1日motif热图、交易活动和地址网络图。目录可定位DAI、USDC、USDT、UST、LUNA相关图形；不将所有这些资产统称为ERC20稳定币。

这是本科研究作品的公开代码入口。论文原文、评分页、数据样本与最强量化发现留在申请顾问受限材料中核对；本页不在未取得原文时写入有冲突的论文分数或样本量。
